# 剪辑台 · 纯剪辑版

## 工程师交接

服务器部署请先阅读 [DEPLOYMENT.md](DEPLOYMENT.md)。本仓库以本地版本 `2c129c2e231e6da822f2b7f59656785f97f9cb11` 的源码快照为基线，不包含旧 Git 历史、本地密钥和用户素材；清除了已跟踪的 TypeScript 构建缓存。

这是私有源码交接仓库，不是已经完成 Linux 服务器验收的发布镜像。上线前需完成部署说明中的安全与功能验收。

独立于 OpenCut-AI 原版的本地剪辑工具。保留视频剪辑、文字、普通特效、字幕文件、音频处理、保存和导出；不调用 AI、不下载模型，不需要 Python、Ollama 或 GPU 服务。

## Windows 本地启动

需要 Node.js 和 Bun（packageManager 为 bun@1.2.18）。

- 双击 `启动剪辑台.cmd`：首次自动安装依赖及构建，随后启动生产版本。
- 修改代码后：`powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Rebuild`
- 开发：`powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Mode Development`
- 地址：http://localhost:3002/projects
- 停止：启动终端按 Ctrl+C。脚本不会关闭其他版本的服务。

项目和媒体存储在该浏览器的 IndexedDB / OPFS。3002 与原版 3000/3001 的存储独立，清除网站数据会删除本地项目。源代码备份不包含浏览器项目；本版不迁移原版项目。

## 特效

选中片段后，点击特效卡片的“应用到选中片段”即可附加效果；也保留原有拖放方式。点击素材库特效的加号添加独立特效轨道。片段上的“特效 N”打开就地列表，支持停用、删除、详细调参和确认清空。窄片段使用紧凑徽标或色条，右键和属性面板均可管理。删除/清空均支持撤销。

## 转场

添加转场后，片段尾部会出现蓝青色“转场 · 名称”标记，与紫色特效徽标区分。点击标记可查看名称、时长并删除；也可在片段右键菜单或右侧“已添加转场”卡片删除。极窄片段保留色条，通过右键/属性操作。仅移除转场，原片段和特效保留，Ctrl+Z 可恢复。

## 字幕

在字幕面板手动输入时间和内容，或导入 SRT/VTT。导入生成普通文字轨道，一次撤销可恢复。点击字幕到右侧修改文本、样式；选定文字轨道可本地导出 SRT/VTT。

## 本地音频

在「音频」页点击「上传音频」或拖入自己的配乐、录音、音效，建议使用 MP3 / WAV。导入后与「媒体」页共用同一份项目素材，支持试听、停止和添加到当前播放头位置；加入轨道后可剪切、调节音量、删除，Ctrl+Z 可撤销轨道操作。试听一次只播放一条，切换面板或开始时间线播放会停止试听；同一项目内切换面板不会取消已开始的导入。

音频文件保存在当前浏览器的项目存储中，不会自动上传网站或云端，请保留原文件。现阶段隐藏未配置的在线音效库、收藏和未实现的歌曲页，不再因打开音频面板请求这些服务；原有媒体及旧项目中的库音频不删除，旧素材许可检查仍保留。

## 验证

页面由内置简中 / 繁中 / 英文切换负责本地化。根节点使用 `translate="no"` / `notranslate` 和 Google 防翻译 meta，避免浏览器翻译替换 React 文字节点，导致 Ctrl+Z 等界面更新出现 `removeChild` 异常。内置翻译只修改文字内容，不替换节点，仍保留素材文字的翻译排除规则。强制忽略这些标记的扩展仍需在此网站关闭。

已打开的旧页面需重新加载一次才能应用此保护。出现恢复页时可重新加载上次保存状态或返回项目列表，未保存修改可能丢失；不要清除网站数据。恢复页提供三语言，独立于编辑器及语言提供器，不自动刷新或删除存储。

浏览器回归：运行 `bun apps/web/scripts/serve-translation-regression.mjs`，打开 `http://127.0.0.1:3003/unprotected` 点击 Run regression 复现旧错误；在 `/protected` 执行同一测试确认撤销/重做正常；`/i18n` 检查三语言文字、Tooltip/无障碍属性和节点身份；`/recovery` 触发错误并检查三语言恢复页及重新加载。此隔离页面模拟翻译的节点替换行为，不是对特定浏览器扩展的保证；不修改 3002 的项目数据。

2026-09-05 本轮验证：158 个单元测试通过，简繁文案覆盖 1796/1796，10 个改动代码文件通过 Biome，生产构建通过。真实浏览器完成上述隔离回归，并在 3002 验收项目验证三语言转场删除/撤销、简中特效删除后关闭弹层再撤销恢复。用户原 Chrome 会话未直接接入，复现的是同类异常；未更改用户项目或原版目录。参考：[React 同类问题](https://github.com/facebook/react/issues/11538)、[HTML 防翻译属性](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/translate)。

```powershell
bun test
bun run i18n:check
bun run build:web
```

## 后续网站部署

本轮仅交付本地运行版本。部署前配置 NEXT_PUBLIC_SITE_URL，构建生产版本，使用 Next.js standalone 产物及相应 public / .next/static 资源；HTTPS 环境用于浏览器存储、媒体和录音等能力。账户、云同步及在线素材服务是可选项，部署时使用独立数据库和随机认证密钥，不复用本地示例配置。

`docker-compose.yml` 仅含非 AI 服务：web 配置档为网页，accounts 配置档为可选数据库；不会创建任何模型服务。需自行按主机资源和站点平台配置外部服务。
