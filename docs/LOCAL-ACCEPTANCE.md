## 限制与后续部署

本轮未部署网站、未迁移旧项目，也没有提供商业法律担保。账户/云同步、在线素材 API、反向代理、HTTPS、浏览器存储配额与多用户隔离需要部署时按站点环境验收。启动脚本只监听本机，端口占用时不会强制结束其他服务。重建前先停止本版服务，以免 Windows 锁定正在运行的构建文件。
